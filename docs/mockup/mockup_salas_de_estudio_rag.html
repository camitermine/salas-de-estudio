Arquitectura: ¿Cómo funciona este proyecto RAG?

1. Salas Aisladas (Namespaces): En tu backend (Python/LangChain/LlamaIndex), cada sala corresponde a una colección o namespace en tu base vectorial (Chroma, Pinecone o Qdrant). Así evitas mezclar apuntes de distintas materias.

2. Ingesta & Chunking: Cuando subes un PDF, se extrae el texto, se divide en pedazos (chunks de 512 tokens con overlap de 64) y se generan embeddings vectoriales con un modelo como text-embedding-3-small.

3. Búsqueda y Cita de Fuentes: Al preguntar, tu query se vectoriza, se buscan los K fragmentos con mayor similitud coseno, y se inyectan en el prompt del LLM. El LLM responde citando la página y el archivo exacto.

💡 Tip para tu desarrollo: Puedes añadir en cada chunk metadatos como { "room_id": "...", "page": 12, "source": "apuntes.pdf" } para filtrar y citar con total precisión en el front.
